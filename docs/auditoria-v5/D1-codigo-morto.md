## Síntese

Dos 21 "unused files" do knip, 5 são falsos positivos por estarem fora do grafo de import (3 hooks + `exportar.mjs` + `dre-oracle.mjs`, chamados por config/processo/documentação viva), 14 são código morto de fato (5 componentes React órfãos, 1 fixture de mockup, 1 header pré-v5.6, 6 scripts de debug de migrations já fechadas) e 2 scripts têm propósito ambíguo (`decidir`). Nos 66 exports + 82 tipos não usados, a maior parte é "export por hábito" consumido só dentro do próprio arquivo — a ação correta é remover o `export`, não o código (D1-015 a D1-019). `types/api.ts` (~29 interfaces) e `types/database.ts` (congelado) exigem investigação antes de qualquer remoção.
